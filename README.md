# BRFSS Health Analytics Dashboard (R Shiny)

## Overview
This project presents an interactive health analytics dashboard built using R Shiny, leveraging data from the Behavioral Risk Factor Surveillance System (BRFSS) conducted by the CDC.

The objective is to transform large-scale public health survey data into actionable insights on chronic diseases, lifestyle risk factors, and demographic trends across the United States.

---

## Why This Project Matters
Public health datasets such as BRFSS are complex and high-dimensional. This project demonstrates the ability to:

- Clean and preprocess real-world survey data  
- Perform exploratory data analysis (EDA) at scale  
- Communicate insights through interactive visualizations  
- Build end-to-end analytical applications using R  

---

## Key Features
- Interactive dashboard built using Shiny with dynamic filtering  
- Data cleaning pipeline handling missing values and recoding variables  
- Exploratory analysis of health indicators such as obesity and smoking  
- State-level analysis of health outcomes  
- Interactive visualizations using ggplot2 and plotly  

---

## Tech Stack
- Language: R  
- Framework: shiny  
- Data Manipulation: dplyr, tidyverse  
- Visualization: ggplot2, plotly  

---

## Dataset

## How to Run the Project

1. Install required packages
install.packages(c("shiny", "tidyverse", "plotly"))

2. Run the application
shiny::runApp("app.R")
